# Sikka - Egyptian Railway Companion App
Sekka is a modern, user-centric Flutter application designed to revolutionize the train travel experience in Egypt. It provides passengers with real-time tracking, seamless ticket management, and enhanced safety features, all wrapped in a culturally inspired, sleek UI.

## Key Features
- Live Trip Tracking: Real-time monitoring of train location, and estimated time of arrival (ETA) using GPS integration.

- Interactive Journey Timeline: A visual step-by-step progress bar showing departed, current, and upcoming stations with precise timings.

- Smart Ticket Management: A dedicated section for active and past tickets with QR code support for easy scanning and verification.

- Safety & Emergency Hub: Quick access to emergency contacts and a "Live Location Sharing" feature to keep family informed during the trip.

- Proximity Alerts: Smart notifications that trigger when the train is within 2km of the destination station.

- User Profile Management: Secure storage of user data (National ID, Phone Number) using local or cloud databases.

## Technical Stack
Framework: Flutter (Dart)

State Management: Provider

Database: SQLite (Fire Base)

Navigation: Advanced Bottom Navigation Bar with custom-themed icons.

Location Services: geolocator & Maps_flutter.

UI/UX: Custom-designed widgets focusing on high readability and "Egyptian Railway" branding.
